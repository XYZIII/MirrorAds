MirrorAds сборка __BUILD__

Установка за одну минуту

Одна закладка в браузере. Обновления приходят сами — переустанавливать ничего не нужно.

MirrorAds

Перетащите зелёную кнопку на панель закладок. Если перетаскивание не работает — скопируйте код и создайте закладку вручную.

  1. Покажите панель закладокВ Chrome и браузерах на его основе: Ctrl + Shift + B (на Mac ⌘ + Shift + B).
  2. Добавьте закладкуПеретащите на панель зелёную кнопку «MirrorAds». Или: правый клик по панели → «Добавить страницу» → в поле «URL» вставьте скопированный код.
  3. Откройте Ads Manager и нажмите закладкуДождитесь, пока Ads Manager загрузится, и нажмите «MirrorAds» на панели закладок. Справа откроется окно.
При каждом запуске закладка проверяет, нет ли новой версии, и загружает её сама. Если на странице не Ads Manager, закладка сначала откроет его.
